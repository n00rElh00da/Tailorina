# Tailorina 🧵

Tailorina is an AI-powered web application designed to help customers understand garments and simplify communication with tailors.

The project explores how AI can be used to analyze garment images and extract useful garment information.

## ✨ Current MVP

* Upload a garment image
* Garment analysis interface
* AI-powered analysis prototype
* Responsive React interface
* FastAPI backend in development

## 🛠️ Tech Stack

**Frontend**

* React
* Vite
* JavaScript
* CSS

**Backend**

* Python
* FastAPI

**AI**

* Google Gemini API

**Tools**

* Git & GitHub
* Vercel

## 🚀 Getting Started

### Frontend

```bash
git clone https://github.com/n00rElh00da/Tailorina.git
cd Tailorina
npm install
npm run dev
```

### Backend

```bash
cd back-tailorina
pip install -r requirements.txt
uvicorn main:app --reload
```

Create a `.env` file with your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```
